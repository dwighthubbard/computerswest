# Glossary

## FDM (Fused Deposition Modeling)
A common 3‑D printing technology that extrudes melted thermoplastic filament layer by layer, building the part from the bottom up.

## SLA (Stereolithography)
Uses a laser or light source to cure liquid resin into solid objects, offering high resolution and smooth surface finish.

## Print bed
The build platform where the object is printed. It is often heated to reduce warping and improve adhesion.

## Layer height
The vertical thickness of each printed layer. Smaller values increase resolution but also print time.

## Supports
Temporary structures printed to support overhanging geometry. They are removed after printing.
