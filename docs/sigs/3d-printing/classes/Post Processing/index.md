# Post Processing

This class covers what happens after a print finishes: removing supports, cleaning up surfaces, joining parts, adding hardware, and finishing safely.

## Class Materials

- [Slide Deck](slide-deck.md)
- [Instructor Guide](instructor-guide.md)
- [Attendee Handout](attendee-handout.md)
- [Timing Plan](timing-plan.md)

## Class Goal

By the end of the class, attendees should understand:

- How to remove prints and supports without damaging the part.
- Basic cleanup tools and safety precautions.
- When sanding, filing, deburring, glue, or paint are useful.
- How heat-set inserts and hardware can improve functional parts.
- Why resin post-processing requires special safety steps.

## Suggested Demonstration

Use a finished print with supports or rough edges. Demonstrate safe removal, light deburring, and how a heat-set insert or screw can be used in a printed part.
