# Post Processing: Attendee Handout

## Common Tasks

- Remove print from bed.
- Remove supports.
- Trim strings or blobs.
- File or sand rough edges.
- Glue parts together.
- Add screws, magnets, or heat-set inserts.
- Paint or label the print.

## Safety

- Wear eye protection when clipping supports.
- Use gloves when appropriate.
- Control sanding dust.
- Be careful with blades and deburring tools.
- Follow resin safety rules for uncured resin and wash liquid.

## Useful Tools

- Flush cutters
- Deburring tool
- Needle files
- Sandpaper
- Hobby knife
- Small pliers
- Soldering iron for heat-set inserts
- Glue appropriate to the material
