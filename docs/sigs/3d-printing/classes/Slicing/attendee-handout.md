# Slicing: Attendee Handout

## Basic Workflow

1. Open the model.
2. Choose the correct printer profile.
3. Choose the correct filament profile.
4. Choose a process or quality profile.
5. Orient the model.
6. Decide whether supports are needed.
7. Slice the model.
8. Review preview mode.
9. Send or export the print job.

## Settings To Know

Layer height
: Smaller layers can improve detail but increase print time.

Walls
: Outer perimeters that often affect strength more than infill.

Infill
: Internal structure that supports top layers and adds some strength.

Supports
: Temporary material for steep overhangs.

Brim
: Extra material around the base to improve bed adhesion.

## Beginner Rule

Use a known-good profile, then change one thing at a time.
