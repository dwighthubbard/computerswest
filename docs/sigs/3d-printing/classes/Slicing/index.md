# Slicing

This class introduces slicer software and the basic settings that turn a 3D model into printer instructions. It is designed around OrcaSlicer, but the concepts apply to most slicers.

- [Timing Plan](timing-plan.md)

## Class Goal

By the end of the class, attendees should understand:

- What a slicer does.
- Why printer, filament, and process profiles matter.
- How layer height, walls, infill, supports, and orientation affect a print.
- How to use preview mode before sending a job to the printer.
- Why changing fewer settings is safer for beginners.

## Suggested Demonstration

Load a simple model in OrcaSlicer. Show profile selection, orientation, supports, layer height, infill, slice preview, estimated time, and exported printer instructions.
