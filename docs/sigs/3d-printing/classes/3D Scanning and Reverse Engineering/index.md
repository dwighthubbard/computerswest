# 3D Scanning and Reverse Engineering

This class introduces ways to capture or recreate real-world objects for 3D printing, 
along with the practical limits of scanning.

## Class Goal

By the end of the class, attendees should understand:

- The difference between scanning an object and designing a replacement part.
- Common capture methods: phone scanning, photogrammetry, and dedicated scanners.
- Why scans often need cleanup before printing.
- Why reverse engineering functional parts usually requires measurements.
- When scanning is useful and when CAD is better.

## Suggested Demonstration

Show a scanned decorative object or a phone-scanning workflow if available. Then 
compare it with measuring a simple functional part using calipers to explain why 
scanning is not always enough.
