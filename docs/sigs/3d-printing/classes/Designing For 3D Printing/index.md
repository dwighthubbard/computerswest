# Designing For 3D Printing

This class introduces design choices that make parts easier, stronger, and more reliable to print on common FDM printers.

- [Slide Deck](slide-deck.md)

## Class Goal

By the end of the class, attendees should understand:

- Why orientation affects strength, appearance, and support needs.
- How overhangs, bridges, walls, and tolerances affect printability.
- Why 3D printed parts are often weaker between layers.
- How to design parts that need fewer supports.
- How to plan small test prints before committing to a final design.

## Suggested Demonstration

Show the same simple bracket or hook in two orientations. Compare support material, print time, layer direction, and likely strength.
