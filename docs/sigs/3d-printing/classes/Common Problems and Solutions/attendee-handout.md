# Common Problems and Solutions: Attendee Handout

## First Rule

Change one thing at a time. If you change five settings at once, you will not know 
what helped.

## Quick Checks

- Is the build plate clean?
- Is the correct filament selected in the slicer?
- Is the first layer smooth and attached?
- Is the filament dry?
- Is the model oriented correctly?
- Does preview mode show supports and walls correctly?
- Is the printer making unusual noises?

## Common Symptoms

Poor first layer
: Clean the plate, check Z offset, check bed temperature, slow the first layer.

Warped corners
: Add brim, avoid drafts, use correct bed temperature, consider another material.

Stringing
: Dry filament, lower temperature, check retraction.

Blobs or zits
: Check temperature, seam position, retraction, and filament moisture.

Layer shift
: Check belts, pulleys, collisions, and print speed.

Weak part
: Improve orientation, add walls, increase temperature if layers are not bonding, choose better material.
