# Maintenance and Calibration: Attendee Handout

## Routine Checks

- Clean build plate.
- Inspect nozzle for buildup.
- Check filament path.
- Listen for unusual noises.
- Check belts for obvious looseness or damage.
- Keep rods, screws, or rails maintained according to the printer manual.
- Remove loose filament scraps from the printer.

## Calibration Prints

First-layer test
: Checks bed adhesion and nozzle distance.

Temperature tower
: Helps compare print quality at different temperatures.

Flow test
: Helps tune extrusion amount for a filament.

Retraction test
: Helps reduce stringing.

## Maintenance Log

Record:

- Date.
- Filament used.
- Problem noticed.
- Change made.
- Result.

## Rule

Do not adjust random settings because a print failed. Identify the symptom first.
