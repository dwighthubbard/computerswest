# Instructor Guide: Maintenance and Calibration

## Audience

Printer owners or prospective owners who want reliable prints without over-adjusting the machine.

## Key Points

- Maintenance prevents many print problems.
- Cleaning the build plate is simple and high impact.
- Nozzle, extruder, belts, rods, screws, fans, and filament path all matter.
- Calibration should be done intentionally, not randomly.
- Automated calibration helps but does not replace inspection.
- Keep a simple maintenance log.

## Demo Flow

1. Show a printer maintenance checklist.
2. Demonstrate build plate cleaning method appropriate to the plate.
3. Point out nozzle, extruder, belts, rods, fans, and filament path.
4. Show examples of dirty nozzle or worn filament path if available.
5. Explain temperature tower, flow test, and first-layer test.
6. Discuss when to stop and consult printer-specific documentation.

## Common Questions

How often should I clean the plate?
: Whenever adhesion declines or after touching the surface. Oils from fingers can cause failures.

Should I adjust belts often?
: No. Check them when symptoms suggest a problem or when the printer manual recommends it.

Do I need to calibrate everything?
: No. Start with known profiles and calibrate when there is a specific reason.
