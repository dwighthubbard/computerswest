# Maintenance and Calibration

This class introduces routine printer care and basic calibration checks that help keep prints reliable.

- [Slide Deck](slide-deck.md)
- [Instructor Guide](instructor-guide.md)
- [Attendee Handout](attendee-handout.md)
- [Timing Plan](timing-plan.md)

## Class Goal

By the end of the class, attendees should understand:

- What routine maintenance tasks are safe for beginners.
- Why cleaning the build plate matters.
- How belts, nozzles, filament path, and lubrication affect print quality.
- What calibration prints can and cannot tell you.
- Why printer-specific manuals and maintenance logs matter.

## Suggested Demonstration

Show a basic maintenance checklist and physical examples if available: clean build plate, nozzle, filament path, belt tension check, and a simple calibration print such as a temperature tower or flow test.
