# Parametric Design: Attendee Handout

## What It Means

Parametric design means the model is controlled by measurements. Instead of redrawing the object, you change values such as length, width, hole diameter, or wall thickness.

## Good Uses

- Spacers
- Boxes
- Brackets
- Cable clips
- Drawer organizers
- Adapters
- Replacement knobs or feet

## Useful Habits

- Measure with calipers.
- Write down dimensions before modeling.
- Name parameters clearly.
- Change one parameter at a time.
- Test with small prints before printing the final object.

## Why Not Just Scale?

Scaling an STL changes every dimension. That can make screw holes, slots, and wall thickness wrong. Parametric changes are more controlled.
