# Instructor Guide: Parametric Design

## Audience

Attendees who want to customize objects but are not ready for a full CAD course.

## Key Points

- Parametric design uses named dimensions and relationships.
- A small number of clear parameters is better than a complicated model.
- Calipers are important because useful designs usually start with real measurements.
- Constraints keep sketches predictable when dimensions change.
- Parametric models are excellent for repeated variations.

## Demo Flow

1. Show the finished model first.
2. Identify the measurements that should be adjustable.
3. Change one parameter and regenerate the model.
4. Show how a hole or slot changes with the parameter.
5. Export the modified model.
6. Open it in the slicer to confirm scale and shape.

## Tool Options

- OpenSCAD for text-based parametric models.
- Tinkercad for simple visual edits.
- Fusion or Onshape for sketch-based parametric CAD.

## Common Questions

Do I need to learn CAD?
: For serious custom parts, yes eventually. For simple parameter changes, many models can be customized without deep CAD knowledge.

Why not just scale the STL?
: Scaling changes everything, including holes, walls, and fit. Parametric design changes the intended dimensions.
