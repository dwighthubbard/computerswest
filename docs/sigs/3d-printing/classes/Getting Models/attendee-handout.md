# Getting Models: Attendee Handout

## Good Places To Look

- Printables
- MakerWorld
- Thingiverse
- MyMiniFactory
- Thangs
- Cults, when the license and source are acceptable

## Before Downloading

Check:

- Photos of real prints, not only computer renderings.
- File type: STL, 3MF, or source file.
- License and allowed use.
- Whether supports are needed.
- Recommended material and print settings.
- Comments from people who already printed it.
- Whether the model is the right size for your printer.

## Useful Terms

STL
: A common mesh file format that stores the model shape.

3MF
: A newer format that can store model and project information.

Remix
: A modified version of someone else's model.

License
: Rules that explain how the model may be used, changed, or shared.

## Practical Advice

Start with small, proven models. A simple successful print teaches more than a large failed one.
