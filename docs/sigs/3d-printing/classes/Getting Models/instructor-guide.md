# Instructor Guide: Getting Models

## Audience

Beginners who understand the basic 3D printing workflow but do not yet know how to find or evaluate models.

## Key Points

- A printer does not create the object by itself; it needs a digital model.
- STL files describe shape only. 3MF files can include additional project information.
- Source files such as Fusion, Onshape, Blender, or OpenSCAD files are better for editing.
- Download popularity is useful, but photos, comments, and print examples matter more.
- Licenses vary. Personal use, remixing, attribution, and commercial use are not the same thing.

## Demo Flow

1. Open a model repository.
2. Search for a simple practical object such as a cable clip, hook, or spacer.
3. Review photos, model description, print orientation, supports, and comments.
4. Open the license and explain what it permits.
5. Download the file or show where the file would be downloaded.
6. Open the file in a slicer and inspect its size and orientation.

## Common Questions

What site is best?
: No single site is best. Printables, MakerWorld, Thingiverse, MyMiniFactory, and other libraries each have strengths.

Can I sell something I downloaded?
: Only if the license allows it. Many models are personal-use only or require attribution.

Why did a downloaded model fail?
: The model may require a different printer, material, orientation, support strategy, or scale.

## Instructor Notes

Avoid turning this class into a long tour of every model site. The useful skill is evaluating a model before spending time and filament on it.
