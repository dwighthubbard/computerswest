# Introduction to 3D Printing

This class introduces the basic ideas, vocabulary, and workflow of 3D printing. It is designed as a short overview that can be presented in less than 45 minutes.

## Class Goal

By the end of the class, attendees should understand:

- What 3D printing is.
- What kinds of things can be made with 3D printing.
- How a digital 3D model becomes a physical object.
- Why some people should use 3D printing services instead of owning a printer.
- Why owning a printer can still be useful for frequent users and rapid prototyping.

## Suggested Demonstration

Use a simple STL model such as `docs/sigs/3d-printing/example-models/3dbenchy.stl` or another small model that loads quickly in OrcaSlicer.

Show the model, slice it, preview the generated toolpath, and explain that the printer follows the generated G-code instructions to create the physical object one layer at a time.
