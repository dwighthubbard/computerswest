# Introduction to 3D Printing: Attendee Handout

## What Is 3D Printing?

3D printing is a way to create physical objects from digital 3D models. Many beginner printers build objects one thin layer at a time.

## What Can You Make?

Functional examples:

- Replacement parts.
- Brackets, clips, mounts, and adapters.
- Tools, jigs, and fixtures.
- Prototypes to test fit, appearance, and function.

Decorative examples:

- Figurines and display objects.
- Ornaments and gifts.
- Props and cosplay items.
- Educational and architectural models.

## Basic Workflow

1. Get or create a 3D model, often as an STL file.
2. Open the model in slicer software such as OrcaSlicer.
3. Choose printer, material, and print settings.
4. Generate G-code.
5. Transfer the file to the printer by Wi-Fi, USB, SD card, or another supported method.
6. Print the object.
7. Remove supports or clean up the print if needed.

## Useful Terms

STL
: A common 3D model file format.

Slicer
: Software that turns a model into printer instructions.

G-code
: The instructions a printer follows to create the object.

Layer height
: The thickness of each printed layer.

Infill
: The internal structure of a print.

Supports
: Temporary structures used to hold up overhanging parts during printing.

FDM or FFF
: A common type of plastic 3D printing that melts filament.

Resin printing
: A process that uses light to cure liquid resin.

## Reasons Not to Own a Printer

- Some materials require industrial printers.
- Metal printing can require expensive equipment, special power, and fire suppression.
- Resin and some other processes involve chemicals.
- Some materials or processes can create fumes, particles, or toxic gases.
- No single printer can print every material.
- Printers require space, maintenance, calibration, and troubleshooting.

## Reasons to Own a Printer

- You print often.
- You want quick turnaround.
- You want to make low-cost plastic test parts.
- You want to revise designs quickly.
- You want to validate fit, appearance, or function before ordering a specialty material from a service.

## Practical Beginner Advice

- Start with simple models.
- PLA on an FDM printer is often the easiest place to begin.
- Preview the sliced model before printing.
- Watch the first layer of a print.
- Expect occasional failed prints.
- Use print services for materials such as tool steel, titanium, gold, ceramic, or other specialty materials.

## Questions to Ask Before Printing

- Does the object need to be strong, flexible, heat resistant, food safe, decorative, or precise?
- What material is appropriate?
- Is a home printer safe and practical for that material?
- Would a print service be easier or less expensive?
- Is a quick plastic prototype useful before ordering the final part?
