# Timing Plan: Introduction to 3D Printing

This plan is designed for a presentation that fits within 45 minutes.

## 45-Minute Version

| Time | Topic | Notes |
| --- | --- | --- |
| 0:00-0:03 | Welcome and class goal | Explain that this is a beginner overview. |
| 0:03-0:08 | What is 3D printing? | Focus on digital model, additive process, and layer-by-layer printing. |
| 0:08-0:15 | What can be made? | Cover functional and decorative models with physical examples if available. |
| 0:15-0:27 | Process overview | STL, OrcaSlicer, settings, G-code, transfer, print. |
| 0:27-0:34 | Why not own a printer? | Cost, specialty materials, chemicals, fumes, safety, no universal printer. |
| 0:34-0:40 | Why own a printer? | Frequent printing, fast turnaround, inexpensive prototypes, validation before service printing. |
| 0:40-0:45 | Questions and wrap-up | Ask what attendees might want to print and whether ownership or a service fits. |

## Shorter 30-Minute Version

| Time | Topic | Notes |
| --- | --- | --- |
| 0:00-0:03 | Welcome and class goal | Keep introductions brief. |
| 0:03-0:07 | What is 3D printing? | Use the simplest layer-by-layer explanation. |
| 0:07-0:12 | What can be made? | Functional and decorative examples. |
| 0:12-0:22 | Process overview | Spend most of the time on STL, slicer, G-code, and printer transfer. |
| 0:22-0:27 | Own vs service | Cover major tradeoffs. |
| 0:27-0:30 | Questions | End with practical next steps. |

## Demonstration Timing

If showing OrcaSlicer live, reserve 8 to 10 minutes from the process overview section:

1. Open an STL file.
2. Show the build plate and orientation.
3. Show material, layer height, infill, and supports.
4. Slice the model.
5. Show preview mode and explain the G-code path.

Avoid starting a long print during the class unless the first layer is the only planned demonstration. A completed sample print is more reliable for a short session.
